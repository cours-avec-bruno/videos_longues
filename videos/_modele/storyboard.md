# Storyboard

Vue d'ensemble de la vidéo : une ligne par scène. Le détail est dans chaque fiche scène.
Les procédés se choisissent avec le [mode d'emploi](../../docs/direction-artistique/procedes/README.md) et le [catalogue](../../docs/direction-artistique/procedes/catalogue.md) (skill `storyboard-procedes`).

## Grammaire de la vidéo

À fixer **avant** les scènes. On ne la change plus ensuite sans raison.

| Élément | Choix | Procédés |
|---|---|---|
| Lieu ou objet-concept principal | | N04 / N07 / I08 |
| Matières d'image (3 au maximum) et leur rôle | ex. 3D = vécu · papier = explication · archive = preuve | |
| Couleur d'accent | | I02, H05 |
| Palette par chapitre | | I16 |
| Registres typographiques (2 ou 3 au maximum) | ex. serif = narration · mono = machine | H02 |
| Transition de chapitre signature (une seule) | | T01 / T03 / T04 |
| Plants → payoffs | ce qu'on cache ou fait retenir → scène de révélation | N03, N05, M07, T05 |
| Son | silences écrits, respirations, fin | S01, M05, S05 |
| **Signatures** (3 à 5 procédés récurrents) | | |

## Bilan des procédés

À tenir à jour au fil du storyboard. Il sert à vérifier les règles d'usage (budget, procédés uniques, sens constant, pas d'empilement) et à varier d'une vidéo à l'autre.

| Procédé | Scènes | Rôle dans cette vidéo (sens constant) |
|---|---|---|
| | | |

- Nombre de procédés différents : … (cible : 15 à 25)
- Procédés « une fois par vidéo » utilisés : …
- Couche 2 utilisée (et pourquoi) : …
